# hermes-portable

سروری که با این workflow اجرا میشه، هرمس رو دقیقاً با هویت قبلی بالا میاره:
بکاپ `~/.hermes` رو از Cloudflare Worker (R2) دانلود می‌کنه، هرمس رو نصب می‌کنه،
و گیتوی رو استارت می‌زنه — پس تلگرام، حافظه، کرون‌جاب‌ها و مهارت‌ها همون قبلی‌ان.

## Secrets مورد نیاز (توی Settings > Secrets و Actions)
| نام | مقدار |
|-----|-------|
| `TAILSCALE_AUTHKEY` | کلید احراز هویت Tailscale |
| `WORKER_URL` | آدرس ورکر، مثلاً `https://hermes-state-backup.x.r2.cloudflarestorage.com` |
| `WORKER_KEY` | رمز اشتراکی ورکر (برای دانلود بکاپ) |

## نحوه کار
۱. بکاپ از ورکر دانلود میشه
۲. توی `~/.hermes` باز میشه (شامل `.env` با توکن تلگرام)
۳. هرمس نصب میشه
۴. گیتوی استارت میشه ← دقیقاً «خودِ» هرمس بالا میاد

⚠️ دو سرور با یک توکن تلگرام همزمان روشن نباشن (پیام‌ها قاطی میشه).
